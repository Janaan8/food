# Food

Persoonlijke voedingsplanning voor spieropbouw: weekmenu's, meal prep (ma t/m do) en afvinkbare boodschappenlijst met AH-prijzen.

- `index.html` — mobiele webapp: boodschappenlijst, recept en weekplan. Vinkjes worden lokaal op het toestel bewaard (localStorage).
- `Weekmenu YYYY-MM-DD.md` — weekmenu's als notitie, inclusief prijzen en rotatie-ideeën.

Installeren als app op je telefoon: open de GitHub Pages-link, kies in de browser "Toevoegen aan beginscherm".
